# Вклад в проект

Спасибо, что решили помочь `cdekx`! Главная ценность библиотеки — соответствие
актуальному API СДЭК, поэтому любые правки сверяются с
[apidoc.cdek.ru](https://apidoc.cdek.ru/).

## Настройка окружения

```bash
git clone https://github.com/maisiq/cdekx && cd cdekx

# вариант 1 — uv (рекомендуется)
uv sync --group dev

# вариант 2 — pip
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

pre-commit install
```

## Проверки перед PR

```bash
make check          # = ruff + mypy + pytest
make drift          # сверить модели с актуальной OpenAPI-спецификацией СДЭК
make bench          # замер стратегий разбора ответов
```

`make drift` требует сеть: скрипт скачивает спецификацию с
`gateway.cdek.ru` (так же, как это делает портал apidoc.cdek.ru).

Все три должны быть зелёными. CI запускает то же самое на Python 3.10–3.13.

## Стиль кода

* **Форматирование** — `ruff format` (line-length 100), никаких ручных правок стиля.
* **Типизация** — `mypy --strict` для `src/`. Публичные методы обязаны иметь
  аннотации аргументов и возвращаемого значения.
* **Докстринги** — Google-стиль (pydocstyle через ruff `D`). Публичный метод
  без докстринга не принимается: это SDK, документация в коде важнее всего.
* **Язык** — докстринги и комментарии на русском (проект для рынка РФ),
  идентификаторы — на английском.
* **Никаких `Any` без необходимости.** Если схема СДЭК действительно
  свободная — используйте `dict[str, Any]` и опишите это в докстринге.

## Как добавлять метод API

1. Найдите раздел в [`docs/API_COVERAGE.md`](API_COVERAGE.md) и убедитесь,
   что метод не реализован.
2. Скачайте OpenAPI-спецификацию с apidoc.cdek.ru и сверьте путь, параметры и
   схему ответа. **Не гадайте** — СДЭК регулярно меняет детали.
3. Добавьте модели в `src/cdekx/models/<раздел>.py`, экспорт — в
   `models/__init__.py`.
4. Добавьте метод в соответствующий `endpoints/<раздел>.py`.
5. Положите реальный (обезличенный) ответ API в `tests/fixtures/<раздел>/`.
6. Напишите тест на `respx` в `tests/unit/endpoints/`.
7. Обновите `docs/API_COVERAGE.md` (⬜ → ✅), `CHANGELOG.md`, при желании —
   пример в `examples/`.

Шаблон метода эндпоинта:

```python
async def get_something(self, uuid: str) -> Something:
    """Краткое описание (``GET /v2/somethings/{uuid}``).

    Args:
        uuid: идентификатор сущности.

    Returns:
        Модель :class:`Something`.

    Raises:
        NotFoundError: сущность не найдена.
    """
    payload = await self._get(f"{self.base_path}/{uuid}")
    return parse_model(Something, payload)
```

## Тесты

* **unit** (`tests/unit/`) — только `respx`-моки, без сети. Должны проходить
  за секунды.
* **contract** — фикстуры в `tests/fixtures/` отражают реальные ответы API.
  Обновляя модель, обновляйте фикстуру.
* **integration** (`tests/integration/`) — живые запросы к `api.edu.cdek.ru`.
  Запускаются только вручную:

  ```bash
  CDEKX_RUN_INTEGRATION=1 CDEKX_CLIENT_ID=... CDEKX_CLIENT_SECRET=... pytest -m integration
  ```

  Интеграционные тесты **не** должны создавать заказы на боевой среде и **не**
  должны попадать в обязательный CI.

## Секреты

Никогда не коммитьте учётные данные. `.env` в `.gitignore`; для локальных
запусков копируйте `.env.example`. Тестовые ключи СДЭК из документации —
публичные, их использование допустимо.

## Процесс релиза

1. `src/cdekx/_version.py` — новая версия (semver).
2. `CHANGELOG.md` — перенести записи из `Unreleased` в новую секцию.
3. `make check && make build`.
4. PR → мерж → тег `vX.Y.Z` → публикация выполняется CI.

## Лицензия

Проект распространяется под Apache-2.0. Отправляя изменения, вы соглашаетесь
с их публикацией на этих условиях и с тем, что ваш вклад лицензируется
согласно `LICENSE` (стандартная практика Apache-2.0, раздел 5).

Если вы добавляете код, заимствованный из другого проекта, — укажите источник
и его лицензию в PR. Код под копилефт-лицензиями (GPL/AGPL) приниматься не может:
проект распространяется под пермиссивной Apache-2.0.

Напоминание по сути проекта: мы реализуем **публичный API СДЭК** по его
OpenAPI-спецификации. Совпадение имён полей, путей методов и значений
справочников с другими клиентами СДЭК нормально и ожидаемо — это факты о внешнем
API, а не чужой код. Копировать чужие реализации при этом не нужно: сверяйтесь
со спецификацией (`make drift`).
